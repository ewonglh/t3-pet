# Icons

Set: Lucide (https://lucide.dev), ISC licence, copyright Lucide Contributors (parts derived from Feather, MIT, copyright Cole Bemis). Paths were written inline as SVG `<symbol>` elements in each HTML file, 24x24 viewBox, 1.75px round-capped stroke (changed from 2px in revision 2), `currentColor`. No runtime CDN. Keep the licence text with the app when these are bundled.

Caveat: the paths were typed from memory of the Lucide set, not copied from the package. Before shipping, diff them against the `lucide-static` SVGs.
